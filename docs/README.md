# Docs

Research notes and reference material for this project.

## Contents

- [`personality-assessments.md`](personality-assessments.md) — survey of the major
  personality frameworks and quizzes (Big Five, HEXACO, MBTI, Enneagram, DISC,

  strength of the evidence, and licensing considerations.

## Conventions

bottom of each document.
